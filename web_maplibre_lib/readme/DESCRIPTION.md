This module bundles [MapLibre GL JS](https://maplibre.org/) 5.9.0 (BSD-3) and
the [PMTiles](https://github.com/protomaps/PMTiles) protocol 4.3.0 (BSD-3) in the
Odoo backend, and stores the map style configuration used by the MapLibre
view modules.

MapLibre GL renders vector tiles with WebGL: smooth zoom, client-side styling
and fast clustering of thousands of points.
