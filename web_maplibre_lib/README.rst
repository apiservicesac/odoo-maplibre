This module bundles `MapLibre GL JS <https://maplibre.org/>`__ 5.9.0
(BSD-3) and the `PMTiles <https://github.com/protomaps/PMTiles>`__
protocol 4.3.0 (BSD-3) in the Odoo backend, and stores the map style
configuration used by the MapLibre view modules.

MapLibre GL renders vector tiles with WebGL: smooth zoom, client-side
styling and fast clustering of thousands of points.

Configuration
=============

System parameters (Settings > Technical > System Parameters):

+------------------------+---------------------------------------------+
| Key                    | Description                                 |
+========================+=============================================+
| ``maplibre.style_url`` | URL of a MapLibre ``style.json``. Default:  |
|                        | OpenFreeMap Liberty (OpenStreetMap data, no |
|                        | API key).                                   |
+------------------------+---------------------------------------------+
| ``maplibre.api_key``   | Optional. Replaces the ``{key}``            |
|                        | placeholder in the style URL (e.g.          |
|                        | MapTiler).                                  |
+------------------------+---------------------------------------------+

Examples:

- OpenFreeMap (default):
  ``https://tiles.openfreemap.org/styles/liberty``
- MapTiler:
  ``https://api.maptiler.com/maps/streets-v2/style.json?key={key}``
- Self-hosted Protomaps: host your own ``style.json`` that points to a
  ``pmtiles://`` source.

MapLibre GL requires WebGL. Browser-side keys are visible to logged
users; restrict them by domain at the provider.
